# 素材流程教训

记录培正娘 Live2D 工程在素材环节踩过的坑，供后续维护参考。

## 背景

项目里同时存在三类图片：用户提供的参考母版、程序生成的 SVG 源稿、手绘修改的 PNG。做素材对比时曾把 `master/P1-master-no-hands.png` 当成母版，后来确认那是用 AI 生成的重绘稿，真母版是 `master/P1-master-true.png`。参照物错了，据此得出的「缺渐变」「细节差 24 倍」等结论全部作废，后来按真母版重做了对比。

真母版是平涂加粗描边的风格：贝雷帽是深蓝主色加一条浅蓝高光带，头发是大块红色加简单分缕，眼睛是紫色圆加白色高光点，钟楼是红顶、米色墙、圆形钟面，没有多层渐变和复杂阴影。

## 六条教训

### 1. 参照物必须唯一且经过确认

母版只能有一个，并标注来源和确认状态。AI 生成的重绘稿、二次加工稿不能当母版，否则所有对比和判断都会偏。本仓库现在以 `master/P1-master-true.png` 为唯一母版。

### 2. SVG 不能只画基础形状

`hat.svg` 只画了帽檐弧线、缎带和圆扣，钟楼、紫花、校徽三个标志性元素全部缺失，靠手绘后期补。交付的源稿必须是完整部件，标志性元素不能留白。

### 3. 手绘修改要严格对照母版

手绘 `hat.png` 加了母版没有的校徽，钟楼比母版略大，紫花位置和朝向有出入。凭印象补元素会造成「看起来像、细节不对」。每处修改都要对着母版量比例、对位置。

### 4. 源稿和成品不能双轨脱节

SVG 是程序稿，PNG 是手绘成品，手绘修正没有回写 SVG。`draw.cjs` 一旦重跑就会用旧几何覆盖 PNG，钟楼、紫花全部丢失。要么手绘后锁定 PNG 并标注不可重跑，要么把修改回写到 SVG。

### 5. 验收不能只查数量

只校验 attachment 数量、动画条数、图片尺寸，不校验轮廓和母版的偏差，等于没验收。要有逐部件的并排对比，量轮廓、比例、颜色和元素完整度。

### 6. 颜色数不能单独当匹配指标

真母版帽子区域 23,094 色，手绘 27,350 色，SVG 1,156 色。SVG 少是因为纯色块抗锯齿少，不代表风格错误。判断匹配度看轮廓、比例和元素完整度，颜色数只作参考。

## 改进流程

1. 母版唯一化：`master/P1-master-true.png` 为唯一母版，其他图为参考稿。
2. 部件清单化：每个部件（帽、发、身、裙、腿）列出必须包含的标志元素，SVG 交付前逐项核对。
3. 手绘回写：手绘修改后回写 SVG，或在 PNG 旁标注 `hand-edited` 并禁止重跑生成脚本。
4. 逐件对齐：每个部件与母版同区域并排截图，量轮廓和比例误差，偏差超过阈值就返工。
5. 验收清单：数量、尺寸、帧率、轮廓、元素完整度、颜色一致性，逐项过。
